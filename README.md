# ValuAgent-A-Guardrailed-Multi-Agent-Equity-Valuation-System
ValuAgent — a 5-agent equity valuation pipeline built with Google ADK and MCP. Deterministic Python computes all WACC/DCF/DDM math and runs rule-based guardrail checks; Gemini is used only to narrate the final investment memo, never to calculate. Includes a FastAPI dashboard and Cloud Run deployment.
